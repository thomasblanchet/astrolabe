Each error ends with a code in brackets. Below, each code has its cause and its fix, with an example that shows the real message.

Some errors are unproven results rather than mistakes: the checker cannot prove that the code is correct. The setting `allow_unproven` decides which of them it reports, and the note under such an error names the level that lets it pass. See [Configuration](../configuration/).

To silence one line, add `# type: ignore[code]`. To turn a code off, use the `disable_error_code` setting of mypy.

## columns-field-type

**A field of a schema is not a data type.**

<Example name="schemas_errors" />

**Cause.** A field of a `Columns` class has a type that is not a Polars data type or a marker of one, for example `float`.

**Fix.** Give the field a Polars data type, for example `pl.Float64`. For a data type with parameters, use its marker. See [Data types](../data-types/).

## columns-not-closed

**A schema declares closed=False.**

<Example name="err_columns_not_closed" />

**Cause.** The declared columns of a frame are the complete list, so a `Columns` class cannot leave room for other columns.

**Fix.** Delete `closed=False`. To accept other columns, declare a remainder with `other_columns()` and pass it as the second argument: `TypedDataFrame[Loose, Rest]`.

## columns-not-total

**A schema declares an optional column.**

<Example name="schemas_errors" />

**Cause.** A Polars column is never optional: a frame has it, or it does not. `total=False`, `Required[...]` and `NotRequired[...]` have no meaning for a frame.

**Fix.** Delete the marker. For a function that accepts frames with and without a column, declare the column in a remainder promise or use two schemas.

## concat-collision

**A concat combines columns differently depending on the caller.**

<Example name="err_concat_collision" />

**Cause.** A diagonal concat lines up the columns of each frame by name. The remainder of one frame can hold a name that another frame declares, so the set of shared names depends on the caller.

**Fix.** Exclude the names from the remainder with `without=` or `without_prefix=`.

**Level.** An unproven result. It passes at the level `possible` and every less strict level.

## duplicate-column

**An operation produces two columns with the same name.**

<Example name="err_duplicate_column" />

**Cause.** Polars refuses a frame with two columns of the same name.

**Fix.** Give one of the columns another name with `.alias(...)`.

## expression-fit

**An argument does not fit its declaration.**

<Example name="tut_declarations" />

**Cause.** An expression argument reads a column that the declaration does not allow, gives a different data type, or treats rows differently: row by row, as an aggregation, or as a fixed value. The message names the first part that fails. The same code reports an argument that is not a typed expression.

**Fix.** Pass an expression that fits, or change the declaration. See [Declare expression types](../../guides/expression-types/).

**Level.** A mismatch is always an error. An argument that is not a typed expression is an unproven result: it passes at the level `asserted`.

## forbidden-column

**A frame breaks a promise of the remainder.**

<Example name="open_frames_without" />

**Cause.** A parameter declares a remainder with a promise, for example `other_columns(without=["notional"])`. The caller's frame breaks it, because it holds an excluded name or data type.

**Fix.** Pass a frame that keeps the promise, for example with `drop(...)` first. See [Open frames](../../guides/open-frames/).

**Level.** A frame that breaks the promise is always an error. An open frame that cannot prove the promise is an unproven result: it passes at the level `asserted`.

## frame-type-not-closed

**A runtime schema call gets an open frame type.**

<Example name="err_frame_type_not_closed" />

**Cause.** `check_schema`, `force_schema` and `assume_schema` give a frame the type that their second argument names. The undeclared columns of an open frame have no data type, so the call cannot check or cast them. A frame type with no schema class declares no column.

**Fix.** Pass a frame type with a schema class and no remainder, for example `TypedDataFrame[Trades]`.

## implicitly-inferred-fallback

**An inferred return type falls back to the plain type.**

<Example name="err_inferred_fallback" />

**Cause.** One value in `infer(...)` has a plain type that the checker does not track, so the whole return type of the function falls back to that plain type. This is an error only with the setting `disallow_implicit_inferred_fallback`.

**Fix.** Type the value, for example with a declaration on the parameter. See [Inferred return types](../../guides/inferred/).

## implicitly-unchecked

**A column of the result has no proven data type.**

<Example name="tut_strict_stated" />

**Cause.** The operation knows the name of the column but cannot prove its data type, for example after `map_elements` without `return_dtype=`. The rest of the result keeps its schema.

**Fix.** State the data type, for example with `return_dtype=`. See [Python functions and Unchecked](../../guides/unchecked/).

**Level.** The note under the error names the level that lets it pass. It depends on the reason.

## implicitly-untyped

**The result of an operation has no known schema.**

<Example name="tut_functions_body" />

**Cause.** The operation cannot prove the schema of its result, so it returns a plain frame. The message states the reason.

**Fix.** Remove the reason: declare the column that the operation reads, write a name as a literal, or give a schema. The note names the level that lets the error pass.

**Level.** The note under the error names the level that lets it pass. It depends on the reason.

## infer-misuse

**infer() or an inferred type has no effect here.**

<Example name="inferred_misuse" />

**Cause.** `infer(...)` is in a function whose return type is not an inferred one, is not the whole value of a `return`, or an inferred type is in a place other than the return type.

**Fix.** Use `infer(...)` around the whole value of each `return` in a function with an inferred return type. See [Inferred return types](../../guides/inferred/).

## invalid-call-shape

**Polars refuses the call for any data.**

<Example name="err_invalid_call_shape" />

**Cause.** The form of the arguments makes the call fail at run time for any data, for example `.explode()` with no columns. A method of a typed frame that the installed release of Polars does not have, such as `gather` before Polars 1.41.0, fails in the same way. So does an argument of a parameter that the installed release does not have, such as `maintain_order` of `merge_sorted` before Polars 1.40.0.

**Fix.** Correct the arguments as the message says.

## invalid-cast

**A cast can never succeed.**

<Example name="expr_errors" />

**Cause.** Polars cannot cast the source data type to the target, whatever the values.

**Fix.** Cast to another data type, or convert the column with a method that fits it, for example `dt.epoch()` for a `Datetime`.

## join-key-dtype

**The keys of a join have data types that do not join.**

<Example name="tut_transform_errors" />

**Cause.** The two sides of a join key have data types that Polars does not join, for example a `String` and an `Int64`.

**Fix.** Cast one key to the data type of the other before the join.

## join-rename

**A join renames columns for some callers and not for others.**

<Example name="open_frames_join_error" />

**Cause.** A join adds a suffix to a right-hand column that has the same name as a left-hand one. The two remainders can share a name, so whether the rename happens depends on the caller.

**Fix.** Declare `disjoint_from=` on one remainder, or `without_suffix=` on the left one, as the message says. See [Open frames](../../guides/open-frames/).

**Level.** An unproven result. It passes at the level `possible` and every less strict level.

## malformed-declaration

**A declaration breaks a rule of form.**

<Example name="decl_malformed" />

**Cause.** A declaration of an expression breaks one of its rules, for example it reads no column, reads the same column twice, or has overlapping rows. The checker reports it at the declaration, never at a call.

**Fix.** Correct the declaration as the message says. See [Declare expression types](../../guides/expression-types/).

## marker-arg

**A type argument of a marker has the wrong form.**

<Example name="err_marker_arg" />

**Cause.** A marker such as `TypedDataFrame`, `Minus` or `Datetime` takes arguments of a fixed form. The message names the form.

**Fix.** Write the argument in the form that the message gives.

## marker-arity

**A marker has the wrong number of type arguments.**

<Example name="err_marker_arity" />

**Cause.** A marker takes a fixed number of type arguments, and this one has more or fewer.

**Fix.** Write the number of arguments that the message gives.

## missing-column

**A frame argument lacks a column that the parameter needs.**

<Example name="tut_functions_call" />

**Cause.** The parameter declares a column that the caller's frame does not have.

**Fix.** Pass a frame with the column, for example with `with_columns(...)` first.

## schema-mismatch

**The frames of a stack or a concat do not agree.**

<Example name="err_schema_mismatch" />

**Cause.** `vstack`, `extend`, `merge_sorted` and a vertical or relaxed `pl.concat` need the same columns and data types in each frame. A diagonal concat needs one data type for each shared column.

**Fix.** Give the frames the same schema first, for example with `select(...)` and `cast(...)`.

## selection-rename

**A selection cannot take this rename.**

<Example name="sel_names" />

**Cause.** A selection can pick several columns, but `.alias(...)` gives only one name.

**Fix.** Use `.name.suffix(...)` or `.name.prefix(...)`. See [Selections](../../guides/selections/).

## undeclared-column

**The checker cannot prove that a column exists.**

<Example name="open_frames_undeclared" />

**Cause.** The frame does not declare the name, and its remainder contains it for some callers and not for others. The operation then fails at run time for at least one caller.

**Fix.** Declare the column in the schema of the parameter. Then every caller must pass it.

**Level.** An unproven result. It passes at the level `possible` and every less strict level.

## unknown-column

**The frame has no column of this name.**

<Example name="tut_load_typo" />

**Cause.** The checker can prove that the frame never holds the name: the frame is closed, or its remainder excludes the name.

**Fix.** Correct the name, or add the column in an earlier step.

## unsupported-dtype-op

**An operation has no result at these data types.**

<Example name="start_overview" />

**Cause.** An operator or a method has no result for the data types of its inputs, for example `String - Float64`. Polars raises at run time.

**Fix.** Cast the inputs to data types that the operation accepts.

## vertical-concat-disallowed

**A vertical concat is not allowed.**

<Example name="err_vertical_concat" />

**Cause.** A vertical concat stacks frames by column position, and a type does not track column order. This is an error only with the setting `disallow_vertical_concat`.

**Fix.** Use `how="diagonal"`, which lines up the columns by name.

## wrong-column-shape

**A column is not in the family that the operation needs.**

<Example name="ops_explode" />

**Cause.** The operation needs a family of data types, for example `.explode()` needs a `List` or an `Array`, and `.filter()` needs a `Boolean`.

**Fix.** Pass a column of that family, or convert the column first.

## wrong-dtype

**A frame argument has a declared column with another data type.**

<Example name="err_wrong_dtype" />

**Cause.** The parameter is an open frame that declares a column, and the caller's frame has that column with a different data type. For a closed frame parameter, mypy reports the same fault as `[arg-type]`.

**Fix.** Cast the column to the declared data type before the call.

## wrong-inferred-variant

**A returned value is not of the declared kind.**

<Example name="inferred_misuse" />

**Cause.** A function with `InferredExpr` must return expressions, and a function with `InferredDataFrame` or `InferredLazyFrame` must return frames of that kind.

**Fix.** Return a value of the declared kind, or change the return type.
