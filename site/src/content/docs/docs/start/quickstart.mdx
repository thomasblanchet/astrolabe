## Declare a schema

A schema lists the columns of a frame and their data types. You write it as a class that inherits from `Columns`: each field is a column, and the type of the field is a Polars data type. To type a frame with the schema, write `TypedDataFrame[Trades]`.

Run mypy. The checker reports the line with the typo, because the frame has no column named `prices`. Without Astrolabe, this mistake shows up only when the code runs.

## Fix the mistake, and read a type

Correct the name to `price`. Then add a column with `with_columns`, and ask mypy for the type of the result with `reveal_type`:

<Example name="quickstart_fixed" />

The result has the two original columns, plus the new column `doubled`. Its data type is `Float64`, because in Polars a `Float64` multiplied by an integer gives a `Float64`. The checker works out that type with the typing rules of Polars, so every later step knows that `doubled` exists, and what data type it has.
