## Declare a schema

A schema is a class that inherits from `Columns`. Each field is a column, with a Polars data type. Use the schema in the type `TypedDataFrame`:

<Example name="quickstart_check" />

Run mypy. The function sorts by `prices`, and the frame has `price`, so the checker reports the line.

## Fix the fault, and read a type

Correct the name. Then ask mypy for the type of a new frame with `reveal_type`:

<Example name="quickstart_fixed" />

The new column `doubled` has the data type `Float64`, because a `Float64` times an integer gives a `Float64` in Polars. The checker computes that type with the rules of Polars, so each later step knows the column and its data type.
