Astrolabe needs Python 3.12 or later, mypy 1.13 or later, and Polars 1.43.2.

## Install the package

<Tabs syncKey="package-manager">
<TabItem label="uv">

```sh
uv add git+https://github.com/thomasblanchet/astrolabe
```

</TabItem>
<TabItem label="pip">

```sh
pip install git+https://github.com/thomasblanchet/astrolabe
```

</TabItem>
<TabItem label="Poetry">

poetry add git+https://github.com/thomasblanchet/astrolabe

</TabItem>

## Set up the project

In your project directory, run:

<Tabs syncKey="package-manager">
<TabItem label="uv">

```sh
uv run astrolabe init
```

</TabItem>
<TabItem label="pip">

```sh
astrolabe init
```

</TabItem>
<TabItem label="Poetry">

```sh
poetry run astrolabe init
```

</TabItem>
</Tabs>

The command updates `pyproject.toml`:

- It adds the plugin to `[tool.mypy]` and sets `allow_redefinition = true`.
- It writes a `[tool.astrolabe]` table with every setting at its default, each with a comment.

It keeps your comments and formatting, and running it again changes nothing. Add `--dry-run` to see the changes without writing them. See [CLI](../../reference/cli/) for the other options.

If your mypy configuration lives in `mypy.ini`, `.mypy.ini` or the `[mypy]` section of `setup.cfg`, the command leaves it alone and prints the lines to add instead.

## Set up by hand

Add these lines to `pyproject.toml`:

```toml title="pyproject.toml"
[tool.mypy]
plugins = ["astrolabe.plugin"]
allow_redefinition = true
```

The plugin needs `allow_redefinition = true`. When a loop builds an expression step by step, the variable that holds the expression gets a new expression type at each step, and mypy lets a variable change its type only with this setting. Without it, such an expression never gets its final type. If the setting is off, the plugin prints a warning.

## Run the checker

Then run mypy as usual:

```sh
mypy .
```

The plugin's errors appear wherever mypy runs: in the terminal, in an editor that runs mypy, in pre-commit hooks and in CI. Each one ends with a code in brackets, such as `[unknown-column]`. See [Error codes](../../reference/error-codes/).
