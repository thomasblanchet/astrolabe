Astrolabe is a plugin for mypy. mypy reads the program, holds the types and reports the errors. The plugin adds what mypy cannot work out by itself: the schema of each frame, and the data type of each column.

## The type of an expression holds its code

An expression such as `pl.col("price") * 2` has no data type of its own: its data type depends on the frame that it runs on. On a frame where `price` is a `Float64`, it gives a `Float64`. On a frame where `price` is an `Int64`, it gives an `Int64`. So the plugin cannot give the expression a data type when you write it. Instead, it gives the expression a type that holds its code.

When the expression reaches a frame, for example in `select` or `with_columns`, the plugin reads that code and works out the column that it produces, from the data types of that frame.

## The rules come from Polars

The plugin works out each data type with the typing rules of Polars. The rules are translated from the source code of Polars, and they are tested against Polars itself: a test runs each rule and the real Polars call over many data types, and compares the answers. A few behaviors of Polars follow no rule that the checker can state, and [Polars behaviors](../../spec/polars-behaviors/) lists them.

The rules match one release of Polars, 1.43.2. Another release can type some calls differently.

## Calls are generic

A function that takes an open frame is generic in its remainder, in the same way as a function with a type variable is generic in that variable. At each call, mypy puts the types of the caller into the signature, as it does for any type variable. The plugin then works out what the function does to the columns of the caller. So a function that you write once gives the exact result for every caller.

## The rules are written down

The type system has a written specification, which states what each type means and the rule of each operation. Its core theorems are proved in Lean 4, and every claim that comes from a measurement names the test that measures it. See [the specification](../../spec/how-to-read-it/).
