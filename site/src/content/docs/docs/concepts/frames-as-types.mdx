A type describes a set of values: `int` describes every integer. In the same way, a frame type describes a set of frames: every frame that has certain columns, with certain data types.

## Schema

A schema is the set of columns of a frame, each with a name and a data type. A schema has no order: two frames that have the same columns in a different order have the same schema. The order of the columns belongs to the data, and no type tracks it.

## Closed and open frames

A frame type lists the columns that it declares. It can also have a remainder, which stands for any columns that it does not list. That gives two kinds of frame type:

- A closed frame type has no remainder. It describes the frames that have exactly the declared columns, and no others. `TypedDataFrame[Trades]` is closed.
- An open frame type has a remainder. It describes every frame that has at least the declared columns, plus any others. `TypedDataFrame[Trades, Rest]` is open.

A concrete frame in a program, such as a frame that you read from a file, usually has a closed type. An open type is useful for the parameter of a function that accepts many different frames.

## The remainder follows the caller

A remainder works like the type variable of a generic function. At each call, the checker replaces the remainder with the actual columns of the caller's frame. So the result of the function describes the real frame of each caller, including the columns that the function never mentions.

## A column with an unknown data type

Sometimes the checker knows the name of a column but not its data type, for example when a Python function computes the column. The column then gets the data type `Unchecked`. This keeps the rest of the schema exact, instead of giving up on the whole frame. Every later operation accepts an `Unchecked` column, the way mypy accepts a value of type `Any`.

## Plain frames

A plain frame is a `pl.DataFrame` that the checker does not track. It is the type of a frame whose columns nothing in the code states, such as the result of a reader that gets no schema. The checker reports nothing about plain frames, so code that does not use Astrolabe is checked exactly as before.
