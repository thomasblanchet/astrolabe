Polars code refers to columns by name, as strings: `pl.col("price")`, `select("symbol")`, `join(on="symbol")`. To a type checker, those names are only strings, and every frame has the same type, `pl.DataFrame`, whatever columns it holds. So mypy accepts a misspelled column name, a column that an earlier step dropped, or a filter on a column of the wrong data type. Polars finds these mistakes only when the line runs.

## Mistakes found late

A mistake that only a run of the code can find is found late, and sometimes it is not found at all:

- A pipeline that runs for an hour fails at its last step.
- A branch that handles a rare case runs once a month, and fails when it does.
- A refactor renames a column in one function, and a caller three modules away still reads the old name.

Tests catch some of these mistakes, but only if they run every path of the code with data of every shape.

## What a runtime check gives

A validation library checks a frame against a schema at run time. That is valuable where data enters the program, because a file can always differ from what the code expects. But a runtime check sees only the frames that reach it, on the paths that actually run. It says nothing about the steps between two checks, and it costs time on every run.

## What a static check gives

Astrolabe gives each frame a type that lists its columns and their data types. The checker works out the type of each step from the type of the step before it, with the typing rules of Polars. So it checks every step, on every path, before the code runs, and at no cost at run time.

A frame type is also documentation that cannot go stale. A function that declares the columns that it reads tells every reader, person or coding agent, what it needs. And when a change to the function breaks a caller, the checker reports an error at that caller.

The two kinds of check work together. Check the data once where it enters the program, with `check_schema` or a validation library. From that point on, the checker proves that the code agrees with the data. See [What a type guarantees](../guarantees/).
