A schema is the columns of a frame, each with a name and a data type. A schema has no order. Declare it once, and use it in the type of a frame.

## Declare a schema with a class

A `Columns` class lists the columns. Each field is a column, and its type is a Polars data type. `Columns` declares no column of its own. A subclass inherits the columns of its base:

<Example name="schemas_class" />

`TypedDataFrame[Blotter]` is a closed frame: it has exactly the four columns. To accept a frame with more columns, see [Open frames](../open-frames/).

`TypedDataFrame` with no argument names no column. The checker reads it as the plain frame `pl.DataFrame`, and does not track it. `TypedDataFrame[()]` is a frame with no column.

## Give the parameters of a data type

Some data types have parameters: the time unit of a `Datetime`, the precision of a `Decimal`, the categories of an `Enum`. A field is a type annotation, so it names these data types with a marker:

<Example name="schemas_parameters" />

The checker keeps the parameters. A `Datetime` in microseconds is a different data type from a `Datetime` in milliseconds. See [Data types](../../reference/data-types/) for each marker.

## Keep a data type in a name

A name can hold a data type. Write it as you write it everywhere else in Polars:

<Example name="schemas_names" />

Every declaration that takes a data type as an argument reads such a name, with its parameters: `columns(...)`, `column(...)` and `other_columns(all_of=...)`. A name bound to another name resolves too.

A field is a type annotation, and mypy refuses a variable there. In a `Columns` class, name the data type with its marker: `Stamped = Datetime[Literal["us"], None]` is a type alias, and `time: Stamped` declares the field.

## Rules of a schema

A Polars column is never optional, and the declared columns of a frame are complete. So a `Columns` class has two rules:

- Each field has a Polars data type, or a marker of one.
- The class does not use `total=False`, `closed=False`, `Required[...]` or `NotRequired[...]`.
